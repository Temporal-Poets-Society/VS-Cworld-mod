# Cylinder World design decisions

A record of why Cylinder World is built the way it is. Entries up to CW-D14 are reconstructed (16 October 2026)
from code comments, the README and the version history. Entries from CW-D15 record decisions made on that date or later.
Suite-level direction lives in [overview/DECISIONS.md](../../overview/DECISIONS.md); this file covers this mod only.

Status values: **Active** (implemented and current), **Superseded**, **Proposal** (not implemented, needs agreement).

| CW-D01 | 0.1 | The wrap is a **server teleport by ±circumference** across an identical, flat, misty ocean band, not a wrapped renderer | The game has no world wrapping.
